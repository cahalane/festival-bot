# Knowledge Base

A real festival puts reference material in this directory: amenities (zones, water, toilets, medical, food), geography (stage positions, walk graphs), runbooks (rebuild checklists), and lineup notes. These files are read on demand by agents planning around the festival; they're not loaded by default. For demofest, this directory is mostly symbolic — the fixture is minimal and self-contained — but it establishes the convention so that when you replace demofest with a real festival, you already know where the reference material lives.
